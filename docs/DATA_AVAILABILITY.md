# Data and code availability

The Catawiki component is derived from *Art auction result of prints*, available from
RepOD under the Open Data Commons Open Database License 1.0:
<https://doi.org/10.18150/AEQF8C>.

Spanish auction-house lot records were collected from publicly accessible historical
catalogues and results. Public access does not itself grant a right to redistribute the
complete source database. The row-level extracts, catalogue text and cached pages are
therefore excluded and retained securely for research verification.

This deposit contains the licensed Catawiki analysis data, deterministic transformation
and matching code, source checksums, classification and sample audits, synthetic
validation data, reference inflation series and aggregate model results. These materials
allow inspection of the workflow and execution of public validation checks without
redistributing the protected Spanish source layer.
